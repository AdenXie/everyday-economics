# 日常经济学｜Everyday Economics

[English](README.en.md)

一个基于官方统计数据的开源经济数据探索项目。通过统一起点的指数和同期涨幅比较，帮助读者理解消费价格、工资价格与人均产出的变化。

- 使用澳大利亚统计局（ABS）的季度 CPI 与 WPI 比较物价和工资价格。
- 使用世界银行年度 CPI 与名义人均 GDP，探索十个经济体的长期变化。
- 提供“我的工资跑赢通胀了吗”计算器：用所选地区的官方 CPI 换算两次工资的实际购买力变化，计算只在浏览器本地进行。
- 提供“物价时光机”：把某一时间点的一笔钱按 CPI 折算到另一个时间点，可反向查看，并显示累计物价变化与年均通胀率。
- 提供独立的中英文页面，以及可复核的数据来源和计算方法。

## 本地运行

需要 Node.js 20 或更高版本。基础图表无需配置外部 AI 服务，也无需安装 npm 运行时依赖。

```sh
npm run build
npm run dev
```

打开终端打印的本地地址。中文页面位于根路径，英文页面位于 `/en/`；构建产物保存在 `dist/`。修改源文件后重新构建即可更新预览。

### 国家统计局：中国年度物价与居民收入

中国专题采用免费官方静态数据，覆盖 **2013–2025 年**。2013 年起实行统一城乡住户调查；两种收入均为全体居民的人均年度名义收入（元/人/年），不是每名员工的平均工资或固定工作组合的工资价格指数。

- 可支配收入包括工资性、经营、财产与转移收入；工资性收入是其中一部分。
- CPI 来自《中国统计年鉴 2025》全国定基价格指数（1978 = 100），重标为 2013 = 100；2025 年按官方全年 CPI 与上年持平衔接。来源数值有舍入，扣除 CPI 的结果为近似计算。
- [手工来源摘录](data/sources/china-nbs-annual.json)记录原值、逐年来源、官方链接、取数日和校验值；[生成快照](data/china-nbs.json)供页面使用。早期工资性收入保留来源公布的小数精度，后期按来源使用整数元。
- 更新时先人工核对新的官方年鉴或年度公告、维护摘录及其校验值，再运行 `npm run extract:china` 和完整验证。本专题没有付费接口或定时更新。

## 计算方法

设某项指标的起点为 `X₀`，终点为 `X₁`：

```text
归一化指数(t) = 100 × X(t) / X₀
累计涨幅(%) = 100 × (X₁ / X₀ − 1)
两项涨幅差(百分点) = 指标 A 的涨幅 − 指标 B 的涨幅
按 CPI 指数化的金额 = 起点金额 × 终点 CPI / 起点 CPI
```

年度名义人均 GDP 经 CPI 调整后的变化：

```text
变化(%) = 100 × [(终点人均 GDP / 起点人均 GDP)
              / (终点 CPI / 起点 CPI) − 1]
```

例如物价翻倍、名义人均 GDP 变为三倍，涨幅相差 100 个百分点，但经 CPI 调整后增加 50%。比值与百分点差回答不同问题。

工资计算器使用同一比值方法。澳洲用 ABS 季度 CPI，中国用国家统计局年度 CPI，其他经济体用世界银行年度 CPI；年度 CPI 是全年平均物价水平：

```text
实际购买力变化(%) = 100 × [(终点工资 / 起点工资) / (终点 CPI / 起点 CPI) − 1]
按物价折算需要达到的工资 = 起点工资 × 终点 CPI / 起点 CPI
```

工资按所选地区本币计算，不做汇率换算；两次输入需使用相同口径（同为税前或税后、同为年薪或月薪）。所选时间晚于最新发布期时，计算截止到最新一期并提示。WPI 与居民人均可支配收入只作对照，分别不是平均工资、不是职工工资；名义人均 GDP 不用于工资对照。工资金额不写入网址、浏览器存储或 AI 助手上下文，分享链接只含地区与起止时间。

物价时光机使用相同的 CPI 口径（中国默认世界银行 CPI，可切换为国家统计局 2013—2025，一次计算不混用）：

```text
折算金额 = 金额 × 终点 CPI / 起点 CPI
年均通胀率(%) = 100 × [(较晚 CPI / 较早 CPI)^(1 / 年数) − 1]
```

物价下降时，一笔不动现金的购买力会上升。数据覆盖期内的货币换代按官方固定比率处理：德国 2001 年及以前可按德国马克输入（1 欧元 = 1.95583 马克），俄罗斯 1997 年及以前可按旧卢布输入（1000 旧卢布 = 1 新卢布），韩国 1961 年及以前可按圜输入（10 圜 = 1 韩元）；结果以现行货币显示。其余经济体在所用数据范围内没有需要换算的面额变更，测试中记录了理由。时光机金额不涉及个人信息，分享链接包含地区、金额与起止时间，读取时逐项校验。

- CPI 是加权平均消费价格指标，不是某个家庭的实际账单。
- WPI 衡量可比工作组合的工资价格，不是个人工资、工时或税后收入。
- 人均 GDP 是平均产出，不等于工资或家庭可支配收入。经 CPI 调整的结果也不等同于使用 GDP 平减指数的实际人均 GDP。
- 与 CPI 配对时使用名义人均 GDP；不将已经调整过物价的实际 GDP 再除以 CPI。
- 跨国比较使用各经济体自身的涨幅。未经汇率或购买力平价换算的本币金额不能直接比较高低。
- 若任一累计涨幅的绝对值超过 10,000%，对比条形使用带符号的 `ln(1 + |涨幅|)` 压缩刻度，让其他经济体仍能看清。标签保留真实百分比；压缩后的长度不能用于推算涨幅倍数，页面会显示刻度说明。
- 不混合季度与年度频率，不补造缺失观测，不把不同口径的指数原始点数直接相减。

## 数据更新与校验

ABS 更新需要 Python 和 `openpyxl`，可按以下顺序准备环境和检查数据：

```sh
python -m pip install openpyxl==3.1.5
npm run refresh:abs
npm run refresh:worldbank
npm run extract:worldbank
node tools/record_data_refresh.mjs both
npm run verify
npm test
npm run build
```

通用更新流程为：获取官方来源 → 校验系列定义和原始值 → 生成配对快照 → 更新数据说明 → 测试与构建 → 审阅后发布。源值未变化时保留已有快照；刷新说明仅更新当前数据概况。

- ABS 提取器检查工作簿哈希、系列 ID、定义、频率、单位和原始序列类型。
- 世界银行提取器核对 `canonicalSha256`，再按两项指标都有数据的年份生成连续配对快照。
- `npm run verify` 检查连续性、正值、来源校验及世界银行、中国国家统计局快照的重建一致性。
- 若来源改变口径、布局或覆盖范围，应先确认原因，再调整提取逻辑；不手改生成快照绕过校验。

[ABS 更新任务](.github/workflows/update-abs.yml)支持手动运行；[世界银行更新任务](.github/workflows/update-worldbank.yml)支持季度检查和手动运行。发现数值变化时生成候选分支，经审阅合并后再发布。定时任务不能保证实时执行，必要时可使用相同命令手动检查。

## 通用实现方式

前端读取预先生成的数据快照，计算所选区间的变化并绘制图表。把数据获取和校验与页面展示分离，可以减少运行时外部请求，并让结果可复核。

中英文文案分别保存在 `data/messages.zh.json` 和 `data/messages.en.json`。新增或修改文案时同步维护同一 key，构建时生成各语言静态页面。

生活化讲解将当前区间的百分比翻译为指数与金额示例，并提供明确标注为虚构的生活练习。历史阶段由维护者根据官方资料整理，逐段附来源；读者可将图表切到对应区间。时间范围与来源链接定义在 `src/story-chapters.js`，双语正文仍由文案文件维护。更新历史讲解时，核对来源与快照走势，并区分相关背景与曲线无法独立证明的因果关系。

滚动叙事页（`story/`，英文 `en/story/`）复用同一组历史阶段：图表固定在一侧或屏幕上方，读到哪一段就切换到对应区间并高亮，每段文字自身给出该段的关键数字，最后接到工资计算器。故事结构定义在 `src/scrolly-stories.js`，新增其他经济体时补充快照、历史阶段与双语文案即可。动画遵循系统的减少动态效果设置；段落可用键盘逐段浏览，切换时通过 aria-live 播报。

可选 AI 辅助功能应通过服务端连接模型服务。凭据、模型设置、提示词和请求限制留在服务端；浏览器只传递必要的问题与数据上下文。当前对话仅保存在运行中的页面内存中，刷新后清除。启用外部服务时，应向使用者说明数据处理方式。

折线图支持鼠标悬停、按住或键盘方向键查看对应季度/年度的重标指数与来源原值。手机端从下方坐标轴或独立滚动条左右移动，折线区域用于取数；浏览器长按菜单只在图表区域屏蔽。原指数基期和金额单位不同，差值只比较共同起点重标后的指数。

UI 与图表应保留语义标签、键盘操作、窄屏适配和清晰的单位说明；颜色之外也使用文字或线型区分指标。访问统计如启用，应只收集必要的汇总信息，避免记录对话内容或凭据。
